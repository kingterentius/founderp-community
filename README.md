# FoundERP Community

**An open operating framework for founders who run more than one thing at once.**

FoundERP is the operating system Terence Latimer built to run six brands as one founder. This repository is its open core: the framework, the operating model, and the patterns for putting it to work on everyday tools like Odoo, QuickBooks, and Google Workspace.

## Why this exists

AI is making the billion-dollar, one-person company possible. When it arrives, the bottleneck won't be talent or capital. It will be the system underneath. FoundERP is a working answer to that problem, built in public.

## The framework in one paragraph

Every hour you spend draws on six resources — **S**pace, **T**ime, **R**elationships, **E**nergy, **A**ttention, and **M**oney (**STREAM**) — in service of one of three pillars: **Live** (the life that powers the work), **Give** (what you put into the world), and **Save** (what you protect and build up). A weekly rhythm, **PFOCUSR**, gives each day one job. FoundERP is the system that records all of it, so you can see where you're actually spending yourself.
