# Contributing

Thank you for helping improve FoundERP Community.

## Good contributions

- Clearer explanations, examples, and translations of the framework
- Setup patterns for other tools (Odoo editions, spreadsheets, Notion, and so on)
- Automation blueprints, **with every credential, ID, and personal detail removed**
- Stories of how you've used STREAM or Live / Give / Save — add them to `framework/field-notes/`

## Ground rules

1. **No secrets.** Never commit API keys, passwords, tokens, client data, or record IDs from a live system. Pull requests containing them will be closed.
2. **Plain language.** Write for a founder, not an engineer. Define any technical term the first time you use it.
3. **Licensing.** By contributing, you agree your writing is licensed under CC BY 4.0 and your code under Apache 2.0, as described in [LICENSING.md](LICENSING.md).
4. **Respect the marks.** See [TRADEMARKS.md](TRADEMARKS.md).

## How

Open an issue to discuss bigger changes first. For small fixes, open a pull request directly.
